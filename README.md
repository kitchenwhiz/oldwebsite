# KitchenWhiz — old website archive

An archived copy of the previous www.kitchenwhiz.in website: HTML pages, images and product catalogue PDFs, with the original folder structure kept intact.

- Home page: `index.html`
- Images and catalogue PDFs: `s/`
- Original photos and graphics downloaded from the site: `Images/`
- Squarespace WordPress export (XML) and its images: `manual-download/Wordpress-Export/`
- PDF printouts of each site page: `manual-download/PDF Downloaded/`
